# Bonsai iPad / LLMoniPad 项目调研与接手资料包

**编制日期**：2026-10-11  
**用途**：新开发人员理解项目目标、演进、源码架构、证据基线、真实开发状态以及后续优先级。

请按此顺序阅读：

1. `NEW_DEVELOPER_START_HERE.md` — 新人第一天如何定位分支、阅读代码和避免严重事故。
2. `PROJECT_RESEARCH_AND_HANDOFF.md` — 正式全景调研报告，包括技术分析、完整阶段时间线、风险及测试策略。
3. `EVIDENCE_MATRIX.md` — 各个 Build 的认证条件与不允许外推的结论。
4. `SOURCE_INDEX.md` — 固定源码 SHA 与可复核的一手文件/Actions 链接。
5. `RESEARCH_SNAPSHOT.json` — 机器可读的 GitHub 审查快照信息。

**注意**：Build105 CI SUCCESS ≠ M5 Device PASS。Build106 研发分支处于持续提交状态，报告针对固定快照，必须在后续接手时重新获取远端 HEAD/Actions 状态。

本资料为对原始仓库的只读研究输出，不包含 IPA、模型权重、API Key、用户图片、客户提示词或私有结果 ZIP。
